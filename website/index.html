Connectivity and security

Connect to a trusted computer.

Pair the device and sign in as the owner. A connection path provides reachability; it does not replace authentication.

Connections can use a local network, peer-to-peer connectivity, or an authorized fallback on restricted networks.

The current product is built around a single owner and trusted paired devices.
