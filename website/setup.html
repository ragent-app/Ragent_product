Setup guide

From your computer to your phone.

Ragent runs an instance on a computer you control. Connect a client to manage sessions and work with your configured agents.

1. Get the host

Download the package for your computer’s operating system and architecture. Review its release notes before installation.

Go to downloads →

2. Configure an agent

In the desktop manager, install the harness you want to use and configure a compatible provider. Follow the prompts to authenticate or provide an API key.

3. Connect a client

Open the local web interface on your computer, or connect a trusted mobile device using the pairing options in Ragent. Remote connections require the relevant account and connectivity setup.

4. Start a session

Select a workspace and an available agent and model. Review permission requests before allowing actions.
