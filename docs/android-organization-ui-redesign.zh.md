# Android 团队协作页 UI 实施规格 v3

设计负责人：主代理。2026-11-16。用户已授权恢复 UI 实现。

本规格取代 v2；设计与具体参数由主代理确定。第 10 节为已确认的方案，最新出生、材质和接头调整已接入源码，并有手机抽样观察，完整验收仍待进行；与第 2–4 节有关节点尺寸、连线和图物理动画的冲突参数以第 10 节为准，第 9 节聊天集成、卡片及实时锚点方案继续有效。参考 [Google Design 关于 Gemini 插画系统的说明](https://design.google/library/gemini-ai-visual-design)，其讨论渐变、圆形和有意图的动效；本项目选用安静的单层微渐变，以保持节点可读和界面稳定，不采用塑料高光、多色流动或持续呼吸动画。下列颜色和参数是本项目设计，不是 Google 官方数值。

## 1. 整页排版

- 使用 `LocalRagentColors` 和 `RagentUiFont`，支持原应用所有主题，不引入新全局主题或字体。
- 页面背景 `colors.canvas`；浅色原主题 #F4F4F7、深色原主题 #000000。内容宽度上限 600dp，宽屏居中；手机左右 20dp。
- 页面使用纵向正常布局：导航、任务摘要、图形区域、动态卡。不能把导航/卡片绝对覆盖在图上。
- 状态栏与导航栏 inset 仅消费一次；导航实际高度 56dp，顶部/底部额外间距 8dp。
- 返回与更多按钮各 48dp 触摸区、20dp 图标，圆形低对比背景 `quietSurface`。
- 中央标题胶囊高 48dp，最大宽 216dp；标题 15sp/20sp、Medium，副标题 11sp/15sp、Regular。标题“团队协作”，副标题“n 位成员”；不出现 Revision、Radar、内部 ID。
- 中央胶囊用现有轻玻璃组件的静态 fallback，保留可读性；不添加新的实时模糊或阴影渲染依赖。主图与节点不加玻璃。
- 菜单只放真实可用的“查看任务”“成员消息”“重置视图”；无回调就不显示对应操作。演示重排另见第 7 节。
- 任务区顶部 20dp、底部 12dp。第一行 12sp/18sp 次要色“当前任务”，演示页同一行带“演示”小胶囊（10dp 横向/4dp 纵向内边距）。
- 任务标题 26sp/34sp、Medium，最多 2 行省略；空值“团队工作空间”。状态说明 13sp/20sp、次要色，顶部 6dp，最多 2 行。只映射真实状态，未知写“等待状态更新”。不无条件宣称正在工作。
- 图形区域占剩余可用高度，理想 360dp，最小 280dp，最大 460dp；内部裁剪。紧凑横屏或大字体导致可用高度不足时，整页纵向滚动且图高 300dp，不压扁节点，不裁掉底部内容。
- 动态卡与图间距 12dp，页面底部间距 16dp + 导航栏 inset。无真实发送回调不显示输入框；本轮不添加假的输入框。

## 2. 节点参数

- 节点半径根据真实管理层级取 36/32/28/26dp（直径 72/64/56/52dp），更深管理层维持 26dp；普通叶子半径 24dp（直径 48dp），聚合簇半径 28dp。管理者指明确管理职责或有真实 MANAGES 子节点的成员，沿 parentId 计算深度；普通叶子和仅因被选为布局锚点的成员不升级。缺父或存在循环时保守按明确职责回退。触摸容器为直径与 64dp 的较大值，圆心与布局坐标一致。
- 单层线性微渐变圆面，无描边、额外高光、纹理、光晕或投影。中心使用 Google Material Symbols Rounded 图标，画布色呈镂空观感；半径与图标的静态锚点为 24→22、26→24、28→24、32→28、36→32dp，过渡按第 4 节连续插值；数字簇仍为 20sp。圆外不追加文字。
- 图内所有节点下方、旁边均不显示姓名、角色、状态文字。无障碍仍读完整名字、状态、任务和阻塞信息。
- 职责优先：组织负责人 explore、规划管理 route、阶段负责人 flag、审核 find_in_page；专家/执行者/编写者及未知职责优先使用可识别的专业图标，否则分别回退 psychology/construction/edit_note/person。簇显示 +n。
- 专业图标键共有32个有限视觉类别，不是专业白名单：backend=dns、mobile=smartphone、web=web、runtime=terminal、architecture=schema、database=database、data=analytics、ai=auto_awesome、cloud=cloud、network=hub、hardware=memory、security=shield、testing=bug_report、design=palette、product=category、research=science、writing=edit_note、translation=translate、education=school、business=work、finance=account_balance、legal=balance、health=medical_services、marketing=campaign、sales=storefront、people=groups、operations=settings_suggest、logistics=local_shipping、media=movie、environment=eco、engineering=precision_manufacturing、general=person。android/ios 图标键别名为 mobile。
- 负责人可自由指定任意语言的专业名称。领导 Agent 可在原有分工输出中附加可选 iconKey，不额外调用模型；客户端仅识别明确键，不从名称关键词猜测。未知键回退职责或通用图标，详情和无障碍保留真实名称。图标与许可证来源见 Android 模块 third_party/material-symbols-rounded。
- 三色 stop 为 0、0.55、1，起点 `(0.12W, 0.08H)`，终点 `(0.88W, 0.92H)`；按尺寸缓存画刷。色族浅色 / 深色色表：紫 `#657AA5 #6E76A6 #7B73A1` / `#ADC1E5 #BAC1E9 #C5BEE5`；蓝灰 `#6F8997 #798696 #838293` / `#95B2BE #9EB0BC #A8ADBB`；蓝 `#6487A8 #6E84A6 #7A80A1` / `#92B6D5 #9FB2D4 #AEAED0`；绿 `#64887F #6E887C #7A8A78` / `#98BCAF #A6BCAB #B2BCA8`；暖 `#958263 #9B846C #A08776` / `#C5B58F #CBB69B #D0B7A8`。以 canvas 的相对亮度判断深浅；其他主题不据此宣称对比度全面达标。
- 上述五组依次称紫、蓝灰、蓝、绿、暖色；专业视觉色族为蓝：mobile/web/data/ai/hardware/cloud/network/backend/runtime；紫：architecture/security/design/product/education/legal；绿：database/people/operations/logistics/environment/engineering/general；蓝灰：research/writing/translation/business；暖：testing/finance/health/marketing/sales/media。职责优先或回退时，负责人/专家用紫、管理/阶段负责人用蓝灰、执行者/未知用绿、编写者用蓝、审核用暖色。
- 状态点直径 7dp，外侧画布色隔离环 2dp，圆心位于圆心右下方 (r/√2, r/√2) 处。IDLE 不显示；WORKING/REVIEWING 使用主题 running；WAITING/PROVISIONING/PAUSED 用 secondaryContent；BLOCKED/FAILED 用 error；DONE 用 success。静态状态点，不无限闪烁。
- 按压复用原聊天页 `rememberAgentoPressScale`；不叠加第二套按压动画。
- 单击打开成员只读会话卡，双击保留聚焦；簇点击展开。聚焦尺度 1.06，其他节点透明度 0.50；聚焦主负责人时全体维持 1.0。无焦点默认 1.0。

## 3. 从上往下的松散树形布局

坐标计算统一采用实际图区域的 px，所有 dp 参数乘 density；不使用整屏尺寸作为图区域尺寸。

- 保留真实管理关系、节点、边及既有簇展开语义。兄弟以职责、专业及稳定 ID 排序；遍历设置 visited 防循环，孤立成员仍可见。审核边只表示审核，不据此推导管理关系或伪造父子关系。
- 使用真实 parent 森林，主负责人在世界坐标 (0,0)；每棵树从上往下展开，只有轻微侧倾，不强制左右角色或固定放射轴。
- 叶节点的横向跨度为其触摸宽度 max(2r, 64dp)。有子节点时，跨度为 max(本节点触摸宽度，子树跨度之和 + 24dp × (子树数−1) + 16dp)。兄弟子树按跨度分槽并以父节点为中心。
- 顶层分支的每级横向漂移：只有一个分支时为 −8dp；多个分支时按稳定序号 i 取 8dp × (2i/(n−1)−1)。同一顶层分支的子孙继承该漂移，每向下一层将其加到子槽中心，使树略有侧倾。
- 子节点纵坐标严格向下：childY−parentY = max(父半径 + 子半径 + 28dp × 倍数, |childX−parentX| / tan(40°))；倍数按兄弟序循环取 0.94/1.08/1/0.98。兄弟略微错层，不人为排成整齐横线。
- 向下约束针对遍历时保留的管理树边；异常环中的真实闭合边仍显示，不能保证环内所有边都向下。
- 以全部节点的触摸包络计算默认水平平移并使其尽量居中，再将主负责人的屏幕 x 限制在 W×0.38 至 W×0.62；主负责人屏幕 y 为 clamp(H×0.18, 56dp, 84dp)。布局锚点不改变节点的真实职责。
- 独立组件按自身子树跨度排在主树右侧，组件与主树之间留 32dp；其根位于主负责人下方至少 max(主负责人半径 + 组件根半径 + 32dp, 96dp)，组件内部遵循同样的树形规则，不伪造管理关系。
- 聚焦只使所选节点沿其真实父节点到子节点的方向移动 10dp；独立组件的根向下移动，主负责人不移动。其他节点和默认布局不变，取消聚焦回原位；打开会话卡不改变布局。
- 普通聚焦只改变焦点，不隐式展开聚合簇；点击聚合簇才显式展开，展开属于拓扑变化，可重新布局。
- 大图保留平移缩放能力，不承诺任意拓扑的所有节点同时可见或连线绝不穿越。
- `previousPositions` 不可覆盖新目标坐标而冻结布局；连续运动由 UI 内以 node.id 为 key 的动画状态承接。

## 4. 边与阻尼弹簧

- 成员位置弹簧：归一化质量 1，刚度 k=140，阻尼比 ζ=0.74（等效 c≈17.51）。主负责人：质量1，k=260，ζ=0.92（c≈29.67）。Compose 使用 stiffness/dampingRatio，不把 c 填成阻尼比。
- 节点中途换目标承接当前位置和速度；以 node.id 保留状态，不按列表索引重建。无需持续物理循环；到达目标后静止。
- 层级导致的基础半径变化与连线裁边共用同一动画半径：Full 使用 stiffness320、dampingRatio0.88；Reduced/None 即时到位。
- 图标大小按半径锚点 24→22、26→24、28→24、32→28、36→32dp 分段线性插值，超出范围钳制，避免尺寸过渡中跳变；簇文字保持 20sp。
- 边端点每帧取同一份动画节点坐标。起终点裁至节点当前可见圆周，包含焦点缩放；不能另建不同步 tween。
- 边为连接真实关系的直线，起终点裁至当前动画节点的圆周；不再进行曲线候选搜索或弯曲偏移动画。
- 先前五节点静态几何检查针对旧布局，不能作为此版布局或任意拓扑的验收证据，也不能代表真机动画性能。
- 普通边 1.25dp，secondaryContent 基色 alpha=0.22；审核边同宽、alpha=0.28，虚线 4dp 实/5dp 空，端帽 Round。再乘焦点产生的 edge.alpha，普通默认 edge.alpha=1。
- 本轮不创造后台不存在的通信事件。已有真实粒子不新增随机路径；Reduced/None 下不显示移动粒子。
- 当前 `ParticleUiState` 缺少关联边标识，不能可靠绑定新的动态路径，本轮先不渲染这类游离粒子。保留已有事件和活动数据；真实通信路径接入不作为本轮已完成能力。
- Full：上述弹簧；首次整幅图透明度 0→1，180ms，不把所有节点从同一点弹出。
- 焦点缩放Full使用320/.88弹簧，透明度120ms；Reduced缩放立即到位、透明度100ms；None全部立即。连线裁圆半径使用同一动画缩放值。首次淡入等实际非空节点到达后开始。
- Reduced（主题偏好或 uiState.reduceMotion）：位置立即到位，无回弹；首次淡入 100ms；None：全部立即到位，0ms。不可留下全局动画设置关闭后仍在跑的图动画。
- 图区域缩放/平移复用原能力；不添加单节点拖拽功能。本轮不承诺该功能已存在。

## 5. 动态卡与原有成员详情

- 单击普通成员打开只读会话卡；聚合簇点击仍展开簇。演示成员没有真实会话，以明确空态呈现；离线时保留已授权内存内容并标示未更新，身份变化或撤权清除。
- 卡片位于导航下可用区，左右各 16dp、最大宽 600dp，高为该区 0.82 倍且不超过 640dp，居中放置。正文为独立滚动阅读区，无输入或介入按钮。
- 同一不透明节点圆面连续变成阅读壳：Full 弹簧 stiffness220、dampingRatio1、阈值0.002；Reduced 160ms FastOutSlowIn，None 即时。进度 p 限于 0..1；宽度和中心按 p、长度按 p^1.15 过渡，圆角从半个最短边经 smoothstep(0.10,0.80) 过渡至22dp。
- 节点原三色按 smoothstep(0.15,0.85) 渐变到不透明主题画布色；整体从源节点当前透明度按 smoothstep(0,0.15) 平滑恢复至1，收起时跟随当前目标透明度，再单独应用删除淡出，玻璃层按 smoothstep(0.55,1) 渐显；原角色图标连续移动至卡头，32dp 渐变徽底渐显。状态点在起始位置保留后淡出。正文固定终点尺寸测量，阅读窗口与壳的逻辑起始边对齐，随宽度揭示另一侧边缘；图坐标使用物理坐标，不随文字方向镜像，不缩放，并按 smoothstep(0.75,1) 渐显及边缘柔化；完全展开时底下图和文字不透入。
- 展开及收拢期间图布局继续更新；收拢持续跟随当前渲染节点或包含该成员的聚合簇，背景输入直到收拢完成才恢复。节点临时未测量不等于删除；真实删除时当前卡淡出。关闭时图整体不在可视区则先滚动页面使图重新可见，再以最小平移让目标可见，不改变缩放或树布局；等待期间保留卡片，图暂未测量不提前交还。
- 真实在线前台仅刷新组织状态投影，不因每次刷新重置图；卡片顶部状态来自当前绑定描述，未知时显示未知。授权撤销或身份改变时销毁对应会话内容；成员真实删除则卡片在原位置淡出。连接中断保留已读内存内容并标识未更新，重连重新核验绑定。
- 动态卡圆角26dp、背景quietSurface、内边距18dp，无边框和重阴影。
- 标题“协作动态”15sp/20sp Medium；右侧展开/收起按钮至少48dp触摸区。
- 收起显示最多2条，展开最多6条；每条正文13sp/20sp，最多2行；行间距12dp。只有源数据存在可信时间才显示时间。
- 无事件显示“还没有协作动态”，13sp/20sp 次要色；不显示运行绿点暗示团队正忙。
- 卡片展开 Full 使用尺寸弹簧 stiffness320、dampingRatio0.88；Reduced 100ms淡入且无尺寸弹簧；None立即。尺寸变化自然影响图区域的可用空间与目标坐标。
- 以下为保留的旧成员详情样式，普通节点单击不再进入该入口。成员 sheet 使用原有胶囊玻璃外壳；顶部圆角28dp，横向24dp内边距，底部16dp+导航栏inset。拖拽柄36x4dp，上12dp下16dp。
- 名字22sp/28sp Medium，角色及状态13sp/20sp；任务与活动采用直接文字分段、间距16dp，不堆叠多层小卡片。只有实际有值的进度、文件、阻塞数据才显示。
- 详情可滚动，长名字可换行，状态不能挤出屏幕。操作高度48dp，使用已有按钮样式；无真实回调不显示指令/审批操作。
- 中文/英文文案进入资源，禁止在真实页面凭空补文件、检查点、活动或成功状态。
- 全屏成员详情沿用canvas、最大600dp居中、横20dp，返回触摸48dp/图标20dp，名字22sp/28sp Medium；角色状态13sp/20sp本地化。内容可滚动，段间距24dp，段标题12sp/18sp次要色，正文15sp/24sp，不堆叠卡片。Session ID不占主视图，缺失字段不生成占位事实；无任务显示“暂无任务”。系统返回应先退出详情回到图。

## 6. 包装层与数据

- 真实页、离线页、演示页视觉采用同一导航与内容间距。
- 无快照的离线/错误页复用同一导航：人数未知时不显示人数副标题；无菜单动作时右侧保留48dp空位，不显示无效按钮。该分支自身消费一次系统inset，内容最大600dp居中、横20dp。
- 离线/错误使用quietSurface圆角26dp、24dp内边距；主提示16sp/24sp，辅助13sp/20sp，不在产品UI泄露异常栈。
- 保留认证失效清除缓存、owner/target/session隔离、授权快照只读访问。不得改网络、代理或配对。
- 演示为独立内存数据，不写真实缓存、不发后台请求，继续清晰标注演示。
- 只有一层页面 inset、一层导航；禁止再次在原聊天标题上叠加入口。

## 7. 现有演示的有限交互

- 继续使用用户已授权的5个演示成员，不添加测试数据集或业务测试。
- 演示菜单可放“展开成员 / 收起成员”：复用真实簇/聚焦行为，或提供本地演示视图变化用于观察弹簧；不自动循环、不假装执行后台任务。
- 优先采用双击成员聚焦外移10dp、重置归位展示弹簧；若足够则不增加演示专用控制。
- 不新增人为假动态，只展示已有演示投影的真实字段。空动态就使用空态。

## 8. 执行与验收

- 主代理负责设计参数、审查和最终视觉判断；Terra负责实现。遇到参数冲突回报主代理，不自行换风格。

## 10. 组织图连线、尺寸与拓扑动效（源码已接入，完整验收待进行）

### 连线与节点接合

- 连线以两圆中心轴为基准，线身 3dp；圆周接口约 5dp，经过约 6dp 收束段平滑过渡到线身，圆滑半径约 2dp 并受实际几何限制。取消旧 2dp 空隙，使圆和线无缝、圆滑相切，不出现白缝或暗边；放大、按压、出生及缩放时连接不脱节。线宽保持屏幕视觉尺寸，接口随节点尺寸适配。
- 圆面与接头使用同一绘制坐标、材质和覆盖抗锯齿；图标与触摸层可独立。跨支审核线的中段保持虚线，端头仍圆滑接合，不能误作管理边。共享几何必须包含当前按压 scale。
- 两圆交叠时，以真实椭圆边界接点与切线构造连续桥；接头圆角按到两条真实椭圆边界的外距求解相切圆弧，再以 Bézier 表示，不以原交点补圆。浮点求解失败时回退原桥，是需保留的数学边界，不能据此声称所有几何情况均已证明连续。

### 动态尺寸、可用区与溢出

- 基础叶子直径 48–64dp，手机舒适起点 56dp，根约为叶子的 1.5 倍。按真实管理深度保持父大子小，不凭角色名称或审核边推断管理层级。所有节点使用统一尺度，禁止逐节点 clamp 导致层级大小相同。
- 可用图区域扣除顶部控件和底卡；按实际布局 bounds（含触摸区）适配，目标占可用宽度 88%、高度 86%。触摸区至少 64dp，需防止相互重叠；不为适配额外隐藏成员。稳定状态下屏幕视觉直径下限为 48dp，手动 zoom 也须遵守；达到下限后允许图溢出并拖动，画布裁切不得遮挡顶部控件或底卡。

### 受约束的层级耦合弹簧

- 稳定 nodeId 对应保存单一真实 position、velocity、target、radius 和 lifecycle；布局计算最终落点，出生反作用通过同一位置和速度参与整图耦合，不叠加独立视觉 recoil。质量取 `targetRadius²`，根节点质量再乘 2。

- 出生节点达到目标尺寸 85% 且已离开派发源后显示徽标，避免遮挡芽生。徽标不设独立点击靶，节点统一点击范围覆盖露出圆外的徽标；节点中心、物理半径和展开锚点不因点击范围变化。节点无障碍描述包含动作名称，缺少翻译的 locale 使用平台资源回退。
- 动作由可信的结构化来源投影，来源未知或动作无法确认时不猜测类别、不显示虚假动作。上述动画、可访问性与浅深色效果均等待本轮编译和真机验证。

### 数据覆盖与验证

正式组织在既有 GET 组织投影中批量补充活动快照，不为每个节点另开轮询：同时最多读取 4 个会话，每个活动会话只使用最近 32 条原始事件，并校验节点绑定、会话与当前运行身份。只有可信的结构化操作才能提供具体工具类别；运行中但类别未知不会冒充工具动作。语义不变时投影摘要保持稳定。有限窗口不是完整历史，缺少足够证据时活动保持未知。

Native 节点只使用已验证的委派生命周期：运行、等待、失败及结束等状态可用于清除或显示相应状态，未知来源不推测具体工具。子节点尚无可信的流式响应证据，因此不启用 RESPONDING。根节点使用已有当前轮次和运行身份以及与之匹配的活动操作；流式响应还要求当前运行中明确存在尚未完成的消息。当前轮次缺少运行身份时保守隐藏根动作。

离线、离开前台或请求失败时清除活动；前台连接时以本机最近一次成功收到响应的时间判断新鲜度，连续 15 秒没有成功响应则清为未知。这不是工具事件的存活时间限制：长时间工具只要持续成功刷新，便不会因此过期。

既有 `test-organization-provisioning-route.mjs` 和 `test-provider-native-delegation-runtime.mjs` 检查通过；这不等同于徽标的完整业务或视觉验收。本轮后端尚未部署，Android 编译和真机验证仍待进行。
