# Ragent 2.0 实施状态

本记录描述当前工作区中的实现和证据，不表示已经发布。起始提交为 `64014e687407514f57856a6e7005a1c505483a3e`；工作区含实施前已有未提交修改，提交身份和各阶段最终证据待整合。

## A–C 当前增量

- 本轮通用化增量：责任能力目录区分 GitHub CI、项目资料报告与通用规划；后两者源码沿既有 Factory/ResultPacket 链接入，规划结果可为计划、等待或需要用户输入，计划使用 owner 授权目录、版本和摘要审核。代码能力另需项目 Git 基线、写入范围、检查与独立审查；基线捕获检查已跟踪和未忽略的未跟踪文件，不能声称忽略文件均干净。允许写入范围的实际 staging 内容另有摘要和集成复核。手动或定时观察可触发固定报告；通用计划默认逐次审核，只有 owner 显式授权的受限报告步骤可按政策自动准入。其他动作和外部发布不因此获得授权。上述均未通过真实业务验收。
- 项目资料范围是整个项目而非声称子目录隔离；运行节点必须证明文件系统只读。网络继承需单独确认并仍受现有权限约束，不能据文件只读推断网络隔离；明确要求禁网而无可信证据时拒绝执行。
- 当前可配置的执行目录限项目报告、本地代码工作和独立的 GitHub CI 适配器，不表示任意应用任务或连接器已接通。规划器返回等待时，项目资料没有内容指纹去重，周期重评估可能再次消耗预算；应根据真实需要设置频率和预算。
- A：现有 Factory 链增加依赖对账、独立审查与 owner 验收、受限检查模板、滞留恢复，以及以 Run 正向证据确认状态的约束。相关代码经语法和差异检查；尚无真实任务、重启及完整发布验收。
- B/C：责任、政策、事件、wake 和受限 GitHub CI 入口已有源码接线；责任后台默认关闭。CI 真实登录、失败事件、执行和重启尚未验收。重复观察的持久记录增长风险须在启用前核实。

## D–F 当前增量

- D：责任上下文投影读取已授权责任及活动、同项目记忆提交版本和来源，并通过责任工作关联读取 Factory 合同、候选和执行事实。跨存储读取不是原子快照；责任版本或记忆版本变化时拒绝本次组装。记忆更正与撤销已有预览、确认和版本约束的写入源码，默认关闭时返回 503；显式启用开关才开放，尚未通过真实业务验收。不同身份事实的语义冲突未自动解决；目标修订失效、交接替换、预算窗口及真实长任务恢复仍需分别验收。
- E：邮件和日历完成动作记录执行边界；无法确认的外部效果保持 `unknown_outcome`，不自动重发。Google Calendar 的确定性事件 ID 和内容摘要支持读取匹配事件作为正向回执；无结果或查询失败仍是未知。邮件人工核查仅记录人工观察，不能伪装成提供方回执。设备目录中当前本机安装和在线有直接事实；权限、容量和隔离未知时不当作调度授权。远程双端绑定、签名受理/回执、目标候选读取及源端独立导入已有源码接线；单文件仅支持双方固定授权的 asset/Session、内容摘要和最大 4 MiB，写后未知状态需查询，不能将普通传输视作候选验收。缺失真实 provider 用量时预算继续预留；双实例、撤权竞态和真实跨设备恢复未验收。
- F：Web 和 Android 的组织任务入口可读取责任及活动，并通过原业务接口审阅命令。Android 工作台将现有语音转写草稿传入责任审阅，不自动提交；可经确认保存 Session 责任引用，重新进入时读取并校验版本。活动可显式请求本机 TTS 朗读并停止，离开视图停止朗读；尚未编译或设备验收。暂停责任与停止现有执行分别展示。免手持连续语音及跨设备续接未验收，不能标为已上线。

远程取消回执只证明请求结果。源端仅在匹配的目标签名回执提供真实 Run/Attempt 失败或取消证据时收敛终态；成功结果仍等待独立审查，查不到执行记录保持未知。缺失真实用量继续保留预算预留。

## 检查与限制

本轮责任生命周期源码支持 owner 按版本确认完成、取消和归档，并可在暂停或取消时单独请求停止既有工作。请求不代表执行已停止；旧代次、未知 Run 和先完成但待审核的结果仍需按实际证据处理，归档保留历史。一个 workflow 完成不代表整个持续责任完成。

责任通知在应用内显示活动，Web Push 还需逐责任显式开启、经认证的已绑定 owner 设备及其完整现有订阅凭据、以及服务端 `AGENTOC_RESPONSIBILITY_PUSH_ENABLED=1`；默认关闭。仅面向已绑定订阅定向发送，记录 provider 接受、拒绝或未知，不代表用户已读；发送与撤销跨存储和网络不原子，未知不自动重发。支持的活动包括待审计划、需要输入、阻塞及真实单次工作流完成和预算阻塞；预算事件仅覆盖实际 Governor 拒绝进入 blocked 的路径，freshClaim 已证实未启动而直接失败的路径不覆盖。单次工作流完成不推断整项责任完成。Android FCM 的责任通知未接入；没有真实推送、重启或设备验收。服务工作线程在已有可见窗口时抑制系统通知，多窗口与冷启动跳转仍需验证。

本轮对修改的 JavaScript 做语法检查和静态差异审阅；未新增测试、测试数据或基础设施。Android 组织模块 Kotlin 离线编译以 Gradle `--configure-on-demand` 通过，避免无关 app 配置；直接配置 app 的首次尝试因既有 debug keystore 缺失停止。真实账户、提供方和设备验收尚未完成。恢复中的外部效果不可由本地回滚撤销；结果未知时应保留证据并人工核查。

责任后台需显式 `AGENTOC_RESPONSIBILITY_RUNTIME_ENABLED=1`；记忆写入需 `AGENTOC_RESPONSIBILITY_MEMORY_WRITES_ENABLED=1`；远程新准入需 `AGENTOC_REMOTE_FACTORY_ENABLED=1`，单文件新传输需 `AGENTOC_REMOTE_FILE_TRANSFER_ENABLED=1`，均默认关闭。Factory 控制、调度、组织白名单、Owner 与 Governor 是独立前提。CI runner 需要责任 ID 和 `AGENTOC_CI_OWNER_USERNAME` / `AGENTOC_CI_OWNER_PASSWORD` 环境配置；旧静态 token 登录已退役，既有配置不会自动迁移。回滚先关闭责任与远程新准入，保留读取、观察、取消与对账；未知外部效果不自动重试。源码和语法检查不代表真实 CI、登录、重启、双实例验收或发布；打包前须核对纳入的文件与精确提交。

关闭责任后台只停止新的 wake 处理，既有执行需要单独请求取消并观察 Run/Attempt；不能称为全部停止。Factory 调度开关关闭时，保留有效组织白名单和 scheduler owner 才能启动只观察/对账；若同时清空白名单，自动观察也停止。环境变更按部署生命周期重启生效。
