## 集中真机验收

- 历史长于一屏，首个可见回合部分被顶部裁切时加载旧页；检查正文和像素位置，覆盖顶部留白与重复页。
- 加载旧页期间继续拖动或惯性滚动；不得拉回旧锚点。短历史不足一屏时检查连续补页和最终定位。
- 长流式回复中向上滚动，确认仅看到最后一项的上部不会恢复跟随；手动或惯性到真实末尾后继续输出，确认恢复跟随。
- 输入法打开、关闭和动画期间拖动；检查键盘变化不误触发跟随、不抢阅读位置。
- 刷新、断线重连及快速切换会话，检查旧页、正文、身份和阅读位置；检查流式文本与最终持久消息交接无丢失或重复。
- 展开和收起长用户消息，结合流式更新和分页观察位置；审批在跟随和脱离状态出现、消失时检查视口。
- 普通运行的空稿停止、有稿发送；审批等待时空稿及有稿均可由原按钮停止，草稿和附件保留情况按实际流程核对。
