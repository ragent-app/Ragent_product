# Android 语音处理与电脑 Whisper 管理方案

## 产品规则与优先级

语音处理位置默认为“自动”，但 Whisper 的安装/启停是按电脑管理的，识别位置则按聊天会话决定。这是两个独立维度：Android 设置控制手机本机识别和每台电脑的 Whisper 服务；聊天页右上角三点菜单控制当前聊天使用哪台设备。改变某个设备的服务开关不会改写聊天的手动路由选择。

自动模式每次录音时检查当前聊天绑定的电脑。该电脑已安装并启用 Whisper 时，自动使用这台电脑；这优先于手机本机识别。若电脑未安装、已关闭或不可用，则回退到用户已开启且系统支持的 Android 本机识别。没有可用路线时清楚提示用户，不上传音频、不改草稿。

Android 可以管理每台已配对电脑的 Whisper，包括从手机发起远程安装。安装到某台电脑的 Whisper 安装成功后默认启用并启动；该电脑上的会话在自动模式下随即优先使用电脑处理。Windows Ragent 安装器首次安装时默认勾选 Whisper，接受后安装、启用并启动；用户可以取消。服务只在“已安装且启用”时运行。

识别出的文字只写入聊天输入框草稿，由用户检查并手动发送。语音流程不自动发送消息，也不把录音交给应用云端语音服务。

| 管理位置 | 控制对象 | 生效范围 | 默认行为 |
| --- | --- | --- | --- |
| Android 语音设置 | Android 本机识别 | 本手机 | 用户单独开启；无系统能力时显示不可用 |
| Android 语音设置 | 某台配对电脑的 Whisper | 那一台电脑的所有会话 | 首次安装 Whisper 后默认启用；可单独关闭 |
| 聊天页右上角三点菜单 | 语音处理设备 | 当前聊天 | 自动优先当前聊天所属且已启用 Whisper 的电脑 |

## 设置与状态

语音设置分为两个彼此独立的管理面：Android 本机识别开关，以及每台配对电脑各自的 Whisper 开关。开启或关闭一项不修改另一项。

Android 本机识别只有在设备提供本机识别能力且用户开启时才可用。系统不支持本机识别时明确显示不可用，不切换到网络识别服务。

Android 设置页逐台列出配对电脑，至少显示连接状态、操作系统、Whisper 是否已安装、是否启用、服务运行/就绪状态、当前操作进度和错误原因。状态需区分离线、未安装、安装中、已安装但已关闭、启动中、就绪和错误。仅支持远程安装的 Windows Ragent 显示安装按钮；其他系统可显示状态，但不提供未支持的安装操作。

电脑上的开关只启停服务，不卸载 Whisper。用户关闭后文件保留，且该偏好跨 Ragent 重启和升级保存。

## 聊天页的处理设备

聊天页右上角三点菜单增加“语音处理设备”。选择按聊天保存，默认是“自动”：

- **自动**：优先使用当前聊天所属且已启用 Whisper 的电脑；该电脑没有可用 Whisper 时，使用已开启且可用的手机本机识别。
- **此手机**：固定使用 Android 本机识别。若本机识别关闭或不可用，提示用户，不转到电脑或网络服务。
- **某台电脑**：固定使用指定的已配对电脑。可选择当前会话电脑或其他已配对电脑；目标必须连接、已安装并启用 Whisper。暂不可用时提示原因，不暗中切换设备。

菜单和录音状态要展示用户能读懂的实际去向，例如“自动（当前使用：工作电脑）”“工作电脑（启动中）”“此手机（不可用）”。未安装 Whisper 的电脑不能直接作为识别目标；提示用户到语音设置中安装。

## 自动路由与失败处理

每次录音开始时根据当前聊天重新解析自动路线：

1. 识别当前聊天会话绑定的 Ragent 电脑。
2. 若该电脑已连接、Whisper 已安装且 `enabled=true`，选择该电脑。刚通过 Android 安装或加装的 Whisper 默认处于启用状态，因此该电脑的会话在服务就绪后自动走电脑路线。服务正在启动或加载模型时等待其就绪；不能因为短暂的启动状态改用手机。
3. 若会话电脑离线、未安装 Whisper 或 Whisper 已关闭，则在 Android 本机识别开关已开启且系统支持时选择手机。
4. 若没有可用路线，不上传音频、不改动草稿，并说明要连接哪台电脑或开启哪个开关。

路线在一次录音开始时确定。服务启动失败、识别失败或连接中断时停止本次操作并展示错误，允许用户重试或在三点菜单中改选；不能在录音或音频上传途中悄悄把同一段音频转交另一台设备。切换聊天后，“自动”根据新会话的电脑重新计算；手动选择则保持到用户改回自动或选择别的设备。

## Android 远程安装和控制

用户在 Android 语音设置中，对支持的未安装电脑点击“安装 Whisper”。安装操作由目标 Windows Ragent 执行：

1. 使用现有配对认证和目标授权检查用户是否能管理该电脑，并返回可查询的操作 ID。
2. 目标电脑从固定地址下载固定版本的 Whisper 运行时和多语言基础模型，限制大小并校验 SHA-256；只解压许可清单中的文件。
3. 将运行时安全地写入 Ragent 管理目录，以暂存加原子切换方式激活。失败时清理暂存并回滚，不破坏已有版本。重复请求不能并行重复下载。
4. 安装成功后将该电脑保存为 `enabled=true` 并启动服务。只有服务就绪后，Android 才显示安装成功；安装、校验、解压、启动各阶段均提供明确进度和失败原因。
5. 服务运行时只监听本机回环地址。Android 不直接访问 Whisper 端口，也不发送自定义路径、URL、命令或脚本。

运行时、模型、安装暂存和操作记录放在 Ragent 管理的本地目录。默认放在实例配置目录；Windows 管理员可用受保护的 `HKLM\\Software\\AgentoC\\LocalVoiceSettings\\RuntimeDirectory` 指定另一块本地磁盘。运行时目录仅允许 ControlPlane 服务身份、SYSTEM 和管理员写入；用户语音偏好继续放在受保护的实例配置目录。

Android 的远程开关请求仅允许 `{ "enabled": true|false }`。安装请求仅允许空对象 `{}`。安装和开关操作都要求配对身份认证及目标电脑授权。

## Windows Ragent 安装和服务生命周期

- **首次安装 Ragent**：安装器默认勾选 Whisper 运行时和多语言基础模型。用户保留默认选项时，安装完成后保存为启用状态并启动识别服务；用户取消选项时不安装、不启动。
- **升级时尚未安装 Whisper**：安装器提供默认勾选的加装项。接受后安装、启用并启动；取消后维持未安装。
- **升级时已经安装 Whisper**：保留文件和用户偏好。若用户之前明确关闭服务，升级及重启后仍保持关闭。
- **运行期间**：Ragent 启动时仅在 Whisper 已安装且启用时启动识别服务；启用时随 Ragent 服务启动，关闭时停止服务但保留安装文件。Android 设置和 Windows Ragent 设置可分别管理对应电脑的开关。

首次安装或远程加装成功后，开启服务应由安装流程本身完成；不应要求用户再手动关闭并开启一次才能使服务就绪。

## 语音数据路径

电脑识别时，Android 采集麦克风并编码为受大小限制的单声道 16 kHz WAV，通过现有、已认证且绑定目标电脑的 Ragent 连接发送。电脑端 Ragent 将音频转给只监听 `127.0.0.1` 的 Whisper，再把识别文字返回 Android。选择另一台电脑时必须使用那台电脑自己的已认证连接，不能借用当前会话电脑的身份或通道。

手机识别时，音频只交给 Android 本机识别器，并禁用网络回退。两种方式都只将文字写入草稿；语音 API 不保存音频或转写，聊天消息仍由用户手动发送。

## 接口边界

- `GET /api/local-voice-settings`：返回安装、启用、运行、就绪、安装中和是否可安装状态。
- `PATCH /api/local-voice-settings`：只接受 `{ "enabled": boolean }`，启停已安装服务。
- `POST /api/local-voice-install`：只接受 `{}`，发起固定的 Windows Whisper 安装并返回操作 ID。
- `GET /api/local-voice-install/:operationId`：查询安装进度和结果。
- `POST /api/local-voice-recognition`：接收有大小上限且通过格式检查的 WAV；要求 Whisper 已启用，返回识别文字。

以上接口复用现有 Ragent 配对连接和认证，不开放模型端口给局域网或公网。

## 验收标准

| 场景 | 预期结果 |
| --- | --- |
| 当前会话电脑已安装并启用 Whisper，服务就绪 | 自动使用该电脑，即使手机本机识别也已开启 |
| 当前会话电脑 Whisper 已启用但正在启动 | 自动路线选中该电脑并等待就绪，不切到手机 |
| 当前会话电脑离线、未安装或 Whisper 已关闭 | 自动使用已开启且系统支持的手机本机识别；否则明确提示且不上传音频 |
| Android 对未安装的 Windows Ragent 点击安装 | 目标电脑下载校验、安装、默认启用并启动；就绪后 Android 报成功 |
| Android 用户关闭某电脑 Whisper | 该电脑停止服务但不卸载；该电脑的自动路线转用手机（若手机可用） |
| 三点菜单固定选择手机或某台电脑 | 选择按当前聊天保存；设备不可用时提示，不暗中改路由 |
| 录音中途服务报错或连接断开 | 本次识别失败并可重试；不把同一音频静默发送到另一设备 |
| Ragent 首次安装并保留默认 Whisper 选项 | 安装后服务自动启用并就绪；取消选项则不安装、不运行 |
| 升级前用户已明确关闭 Whisper | 升级与重启后保持关闭 |
| 两种本地识别路线均不可用 | 不发送音频、不改草稿，明确告知如何恢复 |
