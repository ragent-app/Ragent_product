# Android 与 Windows 本地语音处理方案

## 核心体验

语音默认按聊天自动选择处理位置。聊天属于一台已开启 Whisper 的电脑时，Android 自动把该聊天的录音交给这台电脑识别；电脑上的 Whisper 正在启动时，等待它就绪。用户也可以在聊天页右上角三点菜单中，将该聊天固定到手机或任一已配对电脑。

Android 可以查看和管理每台已配对电脑的 Whisper。Windows 电脑尚未安装 Whisper 时，用户可以直接从 Android 发起安装。远程安装成功后，该电脑的 Whisper 默认启用并启动，所以这台电脑上的聊天会自动改由电脑处理。Windows Ragent 安装器首次安装时默认选择 Whisper；保留选项就安装并启用服务，用户可以取消。

识别结果只填入聊天输入框草稿。用户检查后自行发送；语音流程不自动发送消息，也不把音频交给云端语音识别服务。

## 控制项与默认值

安装/启停和聊天路由是两个独立控制面。更改某台电脑的服务开关，不会覆盖聊天里保存的手动设备选择。

| 控制项 | 设置位置 | 作用范围 | 默认行为 |
| --- | --- | --- | --- |
| Android 本机语音识别 | Android 语音设置 | 当前手机 | 用户单独开启；系统不支持时显示不可用 |
| 某台电脑的 Whisper | Android 语音设置或该 Windows Ragent 设置 | 该电脑 | 新安装后默认启用；可停止服务但保留文件 |
| 当前聊天的语音处理设备 | 聊天页右上角三点菜单 | 当前聊天 | 自动优先使用当前聊天所属且已启用的电脑 |

## Android 操作流程

### 管理手机和电脑

Android 语音设置提供手机本机识别开关，并逐台显示已配对电脑的操作系统、连接状态、Whisper 安装状态、服务开关、运行/就绪状态、操作进度和错误原因。

电脑状态需要清楚区分：离线、未安装、安装中、已安装但已关闭、启动中、就绪和错误。支持远程安装的 Windows Ragent 在未安装时显示“安装 Whisper”；其他平台可以显示状态，但不提供尚未实现的远程安装操作。

用户从手机发起安装后，可以看到下载、校验、安装、启动和就绪进度。成功状态表示服务已经就绪，而不只是安装文件已下载。用户可以从同一页面独立启停每台电脑的服务。关闭服务不会卸载 Whisper；重新开启后 Ragent 启动服务。

### 选择聊天的处理设备

聊天页右上角三点菜单增加“语音处理设备”，按聊天保存选择：

- **自动（默认）**：优先使用当前聊天所属电脑的已启用 Whisper；不可用时使用已开启且可用的 Android 本机识别。
- **此手机**：固定使用 Android 本机识别。若本机识别关闭或不可用，说明原因，不转交电脑或网络识别。
- **某台电脑**：固定使用所选配对电脑的 Whisper，可选择会话所属电脑或其他已配对电脑。电脑必须连接、已安装并启用 Whisper；不可用时提示用户，不暗中切换设备。

菜单、录音按钮和录音状态应标明实际路线，例如“自动 · 工作电脑”“工作电脑 · 正在启动”“此手机 · 不可用”。未安装 Whisper 的电脑不能作为识别目标；用户可从语音设置发起安装。

### 录音和草稿

用户开始录音后，Android 先解析当前聊天的有效路线，再采集音频。用户点停止时，电脑路线应先结束采音并完成音频上传和识别；识别处理中再次取消才中止请求。收到转写后只更新草稿，不触发发送。切换聊天时取消旧聊天的进行中录音，避免把结果写入错误会话。

## 自动路由规则

每次录音开始时按以下顺序决定路线：

1. 若聊天保存了手机或电脑的手动选择，只使用该设备。目标不可用时提示用户，不自动换路。
2. 若选择“自动”，读取当前聊天所属的 Ragent 电脑。该电脑上的 Whisper 已安装且启用时，优先选择电脑，即使 Android 本机识别也已开启。
3. Whisper 已启用但仍在启动或载入模型时，保持电脑路线并等待就绪，不立即回退到手机。
4. 当前会话电脑离线、未安装 Whisper 或服务已关闭时，回退到用户已开启且系统支持的 Android 本机识别。
5. 如果没有可用路线，明确提示用户连接/启用电脑或打开手机识别；不上传录音、不改草稿。

路线一旦用于本次录音，识别期间若连接中断或服务报错，只报告失败并允许重试或由用户更改路由；不能把同一段音频悄悄交给另一台设备。切换聊天后，自动模式按新聊天所属电脑重新判断；手动选择保持到用户主动改选或恢复自动。

| 当前聊天及设备状态 | 自动模式行为 |
| --- | --- |
| 会话电脑 Whisper 已安装、启用且就绪 | 使用该电脑 |
| 会话电脑 Whisper 已启用但正在启动 | 等待该电脑就绪 |
| 会话电脑离线、未安装或服务关闭，手机识别已开启且可用 | 使用手机 |
| 电脑和手机都没有可用路线 | 提示如何恢复；不上传、不改草稿 |
| 用户手动选了不可用设备 | 报告该设备不可用；不自动切换 |

## Whisper 安装与服务生命周期

### 从 Android 远程安装

用户在语音设置中对支持的未安装 Windows 电脑点击“安装 Whisper”。目标电脑上的 Ragent 执行安装并返回可轮询的操作 ID：

1. 使用现有配对认证和目标电脑授权确认用户可以管理该电脑。
2. 从固定清单下载固定版本的 Whisper 运行时和多语言基础模型，限制下载大小并校验 SHA-256；只解压许可清单中的文件。
3. 在 Ragent 管理目录暂存文件，通过原子切换激活。失败时清理暂存并回滚，不破坏已有版本；重复请求不得并发重复下载。
4. 安装成功后保存 `enabled=true` 并启动服务。服务就绪后才向 Android 报告成功。
5. Android 后续在该电脑会话中自动路由到 Whisper；用户也可从聊天菜单改用其他设备。

远程安装和启停都只能经已认证、已授权的 Ragent 连接执行。Android 不直连 Whisper 端口，不传 shell 命令、脚本、任意下载地址或自定义路径。

### Windows Ragent 安装、升级和运行

- **首次安装 Ragent**：安装器默认勾选 Whisper 运行时和多语言基础模型。用户保留默认项时，安装后保存为启用状态并启动语音识别服务；用户取消时不安装、不启动。
- **升级时尚未安装 Whisper**：显示默认勾选的 Whisper 加装项。用户接受后安装、启用并启动；取消后维持未安装。
- **升级时已经安装 Whisper**：保留文件和服务偏好。用户此前关闭服务时，升级或重启不得擅自重新启用。
- **服务运行期间**：Ragent 只在 Whisper 已安装且启用时运行识别服务。启用状态随 Ragent 启动；关闭时停止服务但保留文件。用户可从 Windows Ragent 设置或 Android 分别管理对应电脑的开关。

默认把运行时、模型和安装暂存放在 Ragent 受保护的本地配置目录。Windows 管理员可以通过 `HKLM\Software\AgentoC\LocalVoiceSettings\RuntimeDirectory` 指定另一块本地磁盘；目录仅允许 Ragent ControlPlane 服务身份、SYSTEM 和管理员写入。用户语音偏好保存在独立的受保护配置目录。

## 音频路径、接口与安全边界

电脑路线：Android 采集单声道 16 kHz WAV，限制音频时长和大小，通过现有认证连接发送到所选 Ragent；Ragent 将音频交给只监听 `127.0.0.1` 的 Whisper，再将文字返回 Android。选择另一台电脑时，必须使用那台电脑自己的已认证连接。

手机路线：音频交给 Android 本机识别器，并禁用网络回退。两种路线都只把转写写入草稿；不自动发送，不把音频或转写提交到语音识别云服务。

Ragent 接口保持窄范围：

- `GET /api/local-voice-settings`：返回 Whisper 安装、启用、运行、就绪、安装中和是否可安装状态。
- `PATCH /api/local-voice-settings`：仅接受 `{ "enabled": true|false }`，启停已安装服务。
- `POST /api/local-voice-install`：仅接受 `{}`，发起固定的 Windows Whisper 安装并返回操作 ID。
- `GET /api/local-voice-install/:operationId`：查询安装进度和结果。
- `POST /api/local-voice-recognition`：接收大小受限且通过格式检查的 WAV；仅在 Whisper 已启用时识别并返回文字。

以上接口复用现有 Ragent 配对认证和电脑授权；Whisper 服务端口不开放到局域网或公网。

## 验收标准

| 验收场景 | 预期结果 |
| --- | --- |
| Android 对未安装的 Windows Ragent 发起 Whisper 安装 | 目标电脑验证并安装固定载荷，默认启用、启动；就绪后 Android 显示成功 |
| Whisper 刚从 Android 或 Windows 安装器装好 | 服务默认启用；该电脑所属聊天的自动路线使用电脑 Whisper |
| 当前会话电脑 Whisper 已就绪，手机识别也已开启 | 自动使用会话电脑 |
| 当前会话电脑 Whisper 已启用但尚未就绪 | 等待该电脑，不改用手机 |
| 当前会话电脑离线、未安装或已关闭 Whisper | 自动回退到已开启且可用的手机识别；否则说明无法识别 |
| 用户从聊天三点菜单手动选手机或电脑 | 选择仅作用于当前聊天并持久保存；目标不可用时提示，不暗中改路由 |
| 用户关闭电脑 Whisper | 停止服务、保留安装文件；自动模式按规则转用手机 |
| Ragent 升级前用户已关闭 Whisper | 升级和重启后仍保持关闭 |
| 识别时连接断开或服务报错 | 当前识别失败，可重试或手动改路由；不静默转发到其他设备 |
| 识别成功 | 转写只进入当前聊天草稿；不自动发送 |
| 手机和会话电脑都没有可用识别路线 | 不上传音频、不改草稿，提示可操作的恢复方式 |
